CRIMEATHON’26 Problem Statement — Case NS-26-014 (The Northstar Learning Services Investigation)
TRACK: DEFENSE TEAM: SENTRIX (SIMATS)

1. Problem Identification

On 12 October 2026, Northstar Skills Academy experienced an unauthorized data exfiltration incident compromising 2,300 active learner profiles (486 KB CSV). A third-party attendance service identity (svc_rollcall / rc-prod-01) was abused from an unrecognized external IP (203.0.113.77). Root causes encompass: (a) Credential Hygiene Failure: integration INT-01 was active for approximately 7 months (created 04-Mar-2026) with no expiration date (expires: never) and no rotation schedule; (b) Privilege Violation: connector held excessive permissions (learner.search, learner.export) far exceeding attendance needs; (c) Network Enforcement Gap: ip_restriction: not configured permitted external ingress; and (d) Zero-Day Telemetry Gap: absent alerting allowed unmonitored off-hours exfiltration.

3. Confirmed Observations vs. Assumptions & Unknowns

  • Confirmed (Direct Log Evidence): API key rc-prod-01 was utilized from external IP 203.0.113.77 to read configuration (CHG-882), trigger a bulk export (R004), and download 2,300 learner records twice from CampusVault (C003, C004). No rotation or IP boundary existed (INT-01).
  • Investigated Hypotheses (Supported): Credential exposure occurred externally (investigated via ticket HD-1058 screenshot attachment or configuration read).
  • Unknowns / Forensic Boundary: Physical identity of human operator; whether ticket screenshot revealed plaintext secrets; and whether records were distributed onward.

4. Technical & Business Impact

Technical: Exfiltration of 2,300 learner PII records; degradation of ClassBridge portal access; total bypass of network and role boundaries.
Business & Legal: Major liability under Indian DPDP Act; severe reputational damage to Northstar Academy; breach of vendor SLA and trust.

5. Proposed Scope & Intended Outcome

Scope: Implement and validate SENTRIX SHIELD across ClassBridge, CampusVault, and RollCall Connect service identities in an authorized local mock environment.
Intended Outcome: Eliminate external API access via IP allowlisting, strictly enforce least-privilege role boundaries (blocking bulk exports), automate 90-day credential rotation, and provide real-time SIEM anomaly detection with sub-second alert response using heuristic severity ratings (0–100).

6. Selected Track (DEFENSE) & Technical Solution

  • 1. Real-Time Telemetry & SIEM Correlation: Aggregates authentication, gateway, and cloud audit logs to detect off-subnet logins, off-hours access, and abnormal query velocity.
  • 2. Zero-Trust Hardened API Gateway: Restricts connections to approved subnet (10.10.4.12), limits service account scopes strictly to attendance.read, and returns 403 Forbidden on unauthorized paths.
  • 3. Credential Lifecycle & Secret Vault: Replaces perpetual keys with short-lived tokens, enforcing 90-day automated rotation and instant one-click revocation.
  • 4. Interactive Incident Response Dashboard: Full-featured web UI providing live threat scoring, evidence board, visual timeline, attack simulation, and verification test reporting.
