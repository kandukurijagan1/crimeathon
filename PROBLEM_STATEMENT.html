SENTRIX SHIELD: Security Monitoring & Incident Response
CRIMEATHON’26 Problem Statement — Case NS-26-014 (Northstar Investigation)
TRACK: DEFENSE TEAM: SENTRIX (SIMATS)

1. Problem Identification

On 12 October 2026, Northstar Skills Academy experienced a severe data exfiltration incident compromising 2,300 active learner profiles (486 KB). A third-party attendance service identity (svc_rollcall / rc-prod-01) was used from an unrecognized external IP (203.0.113.77) to read integration secrets, execute unauthorized API search queries, and download learner archives from CampusVault. Root failures include: unrotated/unexpiring credentials (14+ months), excessive permissions assigned to the attendance connector, lack of source-IP whitelisting, unredacted credentials exposed in a support ticket screenshot, and absent real-time anomaly alerting.

3. Confirmed Observations vs. Assumptions & Unknowns

  • Confirmed (Direct Log Evidence): API key rc-prod-01 was utilized from external IP 203.0.113.77 to read configuration (CHG-882), trigger a bulk export (R004), and download 2,300 learner records from CampusVault (C003, C004). No rotation or IP boundary existed (INT-01).
  • Strongly Supported: Credential compromised via unredacted configuration screenshot in ticket HD-1058.
  • Unknowns / Excluded Claims: Physical identity of the human operator behind 203.0.113.77 and whether exfiltrated records were distributed onward to third parties.

4. Technical & Business Impact

Technical: Exfiltration of 2,300 learner PII records; degradation of ClassBridge portal access; total bypass of access controls.
Business & Legal: Major liability under Indian DPDP Act; severe reputational damage to Northstar Academy; breach of vendor SLA and trust.

5. Proposed Scope & Intended Outcome

Scope: Implement and validate SENTRIX SHIELD across ClassBridge, CampusVault, and RollCall Connect service identities in an authorized local mock environment.
Intended Outcome: Eliminate external API access via IP allowlisting, strictly enforce least-privilege role boundaries (blocking bulk exports), automate 90-day credential rotation, and provide real-time SIEM anomaly detection with sub-second alert response.

6. Selected Track (DEFENSE) & Technical Solution

SENTRIX SHIELD delivers a four-pillar defense architecture:

  • 1. Real-Time Telemetry & SIEM Correlation: Aggregates authentication, gateway, and cloud audit logs to detect off-subnet logins, off-hours access, and abnormal query velocity.
  • 2. Zero-Trust Hardened API Gateway: Restricts connections to approved subnet (10.10.4.12), limits service account scopes strictly to attendance.read, and returns 403 Forbidden on unauthorized paths.
  • 3. Credential Lifecycle & Secret Vault: Replaces perpetual keys with short-lived tokens, enforcing 90-day automated rotation and instant one-click revocation.
  • 4. Interactive Incident Response Dashboard: Full-featured web UI providing live threat scoring, evidence board, visual timeline, attack simulation, and verification test reporting.
