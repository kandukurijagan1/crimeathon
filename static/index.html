🎯 Defense Playbook
1

Isolate Compromised Credential

Immediately disable svc-rollcall service account and rotate all associated secrets.

2

Assess Blast Radius

Identify all systems and data accessed using the compromised credential. Cross-reference with API logs and data export records.

3

Contain Data Exposure

Revoke access tokens, invalidate API keys, and quarantine exported data files from CampusVault.

4

Implement Detection Controls

Deploy real-time alerting for unusual API volumes, off-hours access, and bulk data exports.

5

Harden Access Policies

Enforce MFA on all accounts, implement least-privilege for service accounts, enable IP whitelisting.

6

Establish Rotation Policy

Mandate 90-day credential rotation, automated alerts 14 days before expiry, and audit logging for all rotations.
